## v2.0.0 (11 October 2026)

- Rebuilt from the ground up for reliability
- Comments now always match the property you're looking at, including when the site changes page without reloading
- The same property now shares its comments between realestate.com.au and domain.com.au, even when the address is written differently (e.g. "St" and "Street"), which also happens between a listing and the property's profile page
- Comments now also work on sold listings, and a property keeps the same comments when it goes from listed to sold, on both sites
- Fixed comments being saved under the wrong address for units written like "Unit 5, 12 Smith Street"
- Listings that hide their address no longer share one comment thread per suburb
- Redesigned comment panel with a calmer look: sits beside the listing instead of covering it, can be resized, and closes when you click outside it
- Light and dark themes: follows your system by default, or pick one with the button in the panel's header
- A “Formatting help” link explains how to format comments, with examples
- The comment button now shows how many comments a property has, and so does the toolbar icon
- Search comments by address, street, suburb or postcode from the new Search tab, without needing to find the property’s listing
- Recent comments and search results now link to the property's page on both sites instead of the original listing, which is often removed once a property is rented or sold
- Sort comments by newest or top
- Your name is remembered for next time (still optional)
- Clearer messages when something goes wrong, with a retry button
